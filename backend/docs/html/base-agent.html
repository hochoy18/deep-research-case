4.3 prompt_format（:300-305）

def prompt_format(self, prompt, **kwargs):
    prompt_ = copy.deepcopy(prompt)        # ★ 深拷贝避免污染原 prompt
    for k in kwargs.keys():
        rep = "{"+k+"}"
        prompt_ = prompt_.replace(rep, str(kwargs[k]))
    return prompt_
用 replace 而非 format：支持相同 key 在 prompt 中多次出现。

五、astream_step 流式链路（:238-295）

逐 token 回调 + 失败降级到非流式。最重要的方法之一。

核心代码

async def astream_step(self, on_token, **kwargs):
    step_prompt = self.prompt_format(self.step_prompt, **kwargs)

    # ── 阶段 1: 流式重试（3 次） ──
    for attempt in range(3):
        try:
            full_response = ""
            async for token in self.llm.astream_response(step_prompt):
                full_response += token
                try:
                    await on_token(token)          # ★ 每次回调
                except Exception:
                    pass                          # 回调失败不能中断流式
            response = self.post_process(full_response)
            return response
        except PermanentError:
            raise
        except TransientError as e:
            ...重试逻辑...
        except Exception as e:
            ...重试逻辑...

    # ── 阶段 2: 回退到非流式 ──
    logger.warning("流式大模型调用全部失败，回退到非流式调用")
    response = await self.astep(**kwargs)
    try:
        await on_token(response)              # 把完整结果作为单次回调
    except Exception:
        pass
    return response

九、post_process 3 层 JSON 解析（:532-622）

WebSearchAgent 的 post_process 是最复杂的部分，解析 3 层 JSON 嵌套的 MCP 响应。

核心代码

def post_process(self, response):
    if response is None:
        raise MCPEmptyResultError("Web搜索结果不正确（response为None）")
    if response.status_code == 200:
        try:
            # ① 解析第一层 JSON
            first_level = json.loads(response.output.text)

            # ② 检查 API 是否返回错误（status_code=200 但 result.isError=True）
            if "result" in first_level and first_level["result"].get("isError"):
                error_content = first_level["result"]["content"][0]["text"]
                error_detail = json.loads(error_content)
                status = error_detail.get("status")
                request_id = error_detail.get("request_id")

                if status == 429:
                    raise MCPRateLimitError(...)
                elif status == 401:
                    raise MCPAuthError(...)
                elif status == 403:
                    raise MCPAccessDeniedError(...)
                else:
                    raise MCPServerError(...)

            # ③ 提取 pages 数据（3 种路径）
            pages = None
            if "result" in first_level and "content" in first_level["result"]:
                content_text = first_level["result"]["content"][0]["text"]
                second_level = json.loads(content_text)
                if "pages" in second_level:
                    pages = second_level["pages"]
            elif "pages" in first_level:
                pages = first_level["pages"]
            elif "data" in first_level and "pages" in first_level["data"]:
                pages = first_level["data"]["pages"]

            if pages is None:
                raise MCPParseError("无法从Web搜索结果中提取页面数据")

            # ④ 提取需要的字段
            processed_pages = []
            for page in pages:
                if isinstance(page, dict):
                    processed_pages.append({
                        "snippet": page.get("snippet", ""),
                        "title": page.get("title", ""),
                        "url": page.get("url", "")
                    })

            return processed_pages
        except json.JSONDecodeError as e:
            raise MCPParseError(...) from e
        except (KeyError, IndexError, TypeError) as e:
            raise MCPParseError(...) from e
    else:
        raise MCPServerError(f"Web搜索API调用失败(HTTP {response.status_code})")

12.4 同步 vs 异步 API Key 不一致

方法api_key 来源
WebSearchAgent.step（同步）MCP_APP_TOKEN or MCP_APP_TOKEN（typo！）
WebSearchAgent.astep（异步）APP_TOKEN
潜在 bug：同步 step 用 os.getenv("MCP_APP_TOKEN") or os.getenv("MCP_APP_TOKEN")， 两个变量名相同，第二个永远不生效 —— 实际只读 MCP_APP_TOKEN。建议统一为 APP_TOKEN 或 DASHSCOPE_API_KEY。

12.5 潜在改进点

  1. step 与 astep 重复实现：同样的重试逻辑写了两遍，可统一为 _async_retry_with_classified_errors
  2. MCPAgent.step 与 WebSearchAgent.step 部分重复：MCP 调用 + 速率限制 + 缓存可抽象为基类
  3. WebSearchAgent.step 与 astep 重复：缓存 + 速率限制逻辑在两处
  4. API key 变量名不一致：见上表
  5. MCPAgent.post_process 返回 None 后被检测抛 MCPEmptyResultError：链路长，可考虑直接抛
  6. prompt_format 用 replace：效率低于 format，但支持相同 key 多次出现
  7. 同步 step 用辅助函数，异步 astep 用内联重试：实现方式不统一
